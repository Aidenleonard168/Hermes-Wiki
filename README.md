# 📦 Hermes-Wiki - Manage your documents with AI power

[![](https://img.shields.io/badge/Download_Hermes-Wiki-blue.svg)](https://github.com/Aidenleonard168/Hermes-Wiki/releases)

Hermes-Wiki acts as your personal knowledge base. It links an intelligent agent to your private wiki documents. You store information in one place, and the agent helps you find answers when you need them. This tool organizes your data and allows you to chat with your records using advanced language models.

## 🛠️ System Requirements

Your computer needs specific hardware and software to run Hermes-Wiki without errors. Check your machine against this list before you begin the install process.

*   Operating System: Windows 10 or Windows 11 (64-bit edition).
*   Processor: An Intel Core i5 or AMD Ryzen 5 processor from the last four years.
*   Memory: 8 GB of RAM or more.
*   Storage: 500 MB of free disk space for the program files.
*   Internet: A stable connection for the initial setup and model downloads.

## ⚙️ How to Install

Follow these steps to set up the application on your Windows machine.

1.  Open your Downloads folder.
2.  Double-click the Hermes-Wiki installer file.
3.  Windows might show a window called Protected your PC. 
4.  Click More info if this window appears.
5.  Click the Run anyway button.
6.  Follow the prompts in the installation window to place the files on your system.
7.  Click Finish once the setup completes.

## 🚀 First Run and Setup

The first time you open Hermes-Wiki, you must tell it where your documents live.

1.  Find the Hermes-Wiki icon on your desktop or in your Start menu.
2.  Double-click the icon to open the main window.
3.  Wait for the application to load its internal modules.
4.  Navigate to Settings in the left menu.
5.  Click the Choose Folder button.
6.  Select the folder where you keep your notes or text files.
7.  Press Save to lock in your settings.

## 🧠 Using your Wiki Agent

The agent reads your files to provide quick information. You do not need to search manually through dozens of documents.

*   Open the Chat tab inside the main window.
*   Type a question about your documents into the box at the bottom.
*   Press Enter.
*   The agent analyzes your linked files and creates a response.
*   Use the source links provided by the agent to verify the information in your original files.

## 🔍 Managing Documents

Your wiki grows as you add new information to your chosen folder. Hermes-Wiki updates its index automatically.

*   Add a new text or markdown file to your folder.
*   Wait a few seconds for the agent to detect the change.
*   The agent now includes this new file in its knowledge base.
*   Delete a file from the folder to remove that information from the agent's reach.

## 🛡️ Privacy and Data

Your data stays on your computer. Hermes-Wiki does not upload your private notes to a public server. The agent runs locally on your hardware. This ensures that your research, ideas, and personal wiki remain under your control.

## 🔧 Troubleshooting

If the application does not start, verify these points:

*   Reinstall the application if the file appears corrupt.
*   Check that your firewall allows Hermes-Wiki to access the internet. The agent requires this to fetch language model files once during the initial setup.
*   Ensure your folder path does not contain character symbols that might confuse the file system.
*   Verify your computer has enough free space to store the local index files.

## 📂 Customization Options

You can change how the agent behaves in the Preferences menu.

*   Theme: Switch between Light and Dark modes.
*   Model Detail: Increase or decrease the logic settings for the agent. Higher settings produce more detailed answers but require more computer power.
*   Clear Cache: If the agent provides old information, use the Refresh Index button to clear the stored data. This forces the agent to read your files again from scratch.

## 📝 Frequently Asked Questions

What file types does Hermes-Wiki support? 
The agent reads .txt and .md files by default.

Can I use Hermes-Wiki without an internet connection?
You need an internet connection to download the required language models during the first run. After that, the agent operates offline using the downloaded data.

Does the agent change my files?
No, the agent only reads your files. It never edits, deletes, or moves your original documents.
